  🌍 AI Guide Travel

AI Guide Travel is an AI-powered travel guide web application designed to help users explore popular destinations through informative travel guides and audio assistance.

🔗 Live Demo: https://aiguidetravel.vercel.app/

⸻

✨ Features

* 🔎 Destination Search
    Search and explore different travel destinations.
* 🗺️ Popular Destinations
    Discover famous places such as:
    * Taj Mahal – Agra
    * Red Fort – New Delhi
    * Gateway of India – Mumbai
    * Hawa Mahal – Jaipur
    * Golden Temple – Amritsar
    * Mysore Palace – Mysore
* 🤖 AI Travel Guide
    Get informative content about the selected destination.
* 📖 Multiple Guide Details
    * Summarized guide – approximately 1 minute
    * Detailed guide – approximately 3 minutes
* 🎧 Audio Guide
    Generate an audio guide for the selected destination.
* 👨 Male Voice Option
* 👩 Female Voice Option
* 📱 User-Friendly Interface
    Simple and easy-to-use interface for exploring destinations.

⸻

🚀 How It Works

1. Open the AI Guide Travel website.
2. Search for a destination.
3. Select the destination you want to explore.
4. Choose between a summarized or detailed guide.
5. Select your preferred audio voice.
6. Generate the audio guide.
7. Listen and explore the destination virtually.

🎯 Project Objective

The main objective of AI Guide Travel is to make travel exploration easier by providing users with quick destination information and an audio-based travel guide.

Instead of reading lengthy travel information, users can select a destination and listen to an audio guide while exploring.
